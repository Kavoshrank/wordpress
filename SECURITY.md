# Security Policy

The KavoshRank team takes security seriously. We appreciate your efforts to responsibly disclose vulnerabilities to help us keep our users and platform safe.

---

## Supported Versions

Only the latest release of the KavoshRank WordPress Plugin receives security updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0.0 | No |

---

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues, discussions, or social media.

Instead, please report security issues privately via email:
- **Email**: security@kavoshrank.ir

Include the following information in your report:
- Type of vulnerability (e.g. XSS, CSRF, SSRF, SQL Injection, Authentication Bypass).
- Step-by-step instructions or Proof of Concept (PoC) to reproduce the vulnerability.
- Potential impact and severity assessment.
- Any suggested fixes or remediation steps.

---

## Response Process

1. **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
2. **Investigation**: We will verify and investigate the reported issue.
3. **Resolution**: If confirmed, we will develop a patch, test it across supported WordPress versions, and release an update.
4. **Disclosure**: Once the patched version is publicly released, we will publish appropriate advisory notices and credit the reporter if desired.
